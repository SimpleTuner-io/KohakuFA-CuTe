# A100

SM80 is supported by the standard strict and automatic APIs. The generic runtime
requires no FlashAttention installation. Additional shared warp-MMA schedules are
selected on the [pinned runtime](../installation.md#qualified-tuned-runtime).

## Tuned selection

The device must be a full 108-SM A100. Inputs are batch 1, aligned contiguous,
equal-shape FP16/BF16 MHA, with no explicit mask or dropout and a positive normal
FP32 scale through `2e38`. Compiled calls and deterministic mode retain ordinary
CuTe dispatch.

| Family | Bound |
| --- | --- |
| D64/D128 | 8–16 heads, 2048–4096 tokens |
| D128 causal with fewer than 16 heads and fewer than 4096 tokens | Only H8/S2048 training with all three input gradients |
| D256 | H16/S1024 or H8/H16 at S4096 |

The medium causal family excludes NoGrad, partial-gradient, and forward-AD calls
from its tuned route. D256/S4096 uses shared V and M64/N64 backward; S1024 keeps
the N32 schedule. Causal ordering uses measured head groups. All paths retain
[the same arithmetic](../precision.md).

## Evidence

[The A100 report](../../results/a100.json) retains the latest measured study for
each workload, including eager and graph calls. It combines distinct source
cohorts without pooling samples or power settings. Its long D256 study beats
FA2 and SDPA in all eight measured backward and joint cases, under both timing
boundaries; forward is unchanged and has small measured regressions.

D64/D128 still have mixed comparisons against FA2. Generic architecture support
is not a performance guarantee. Retained qualification includes statistics,
changed poisoned graphs, independent gradient errors, all four sanitizer tools,
and the common-offset reference-order diagnosis.

Use `tests.test_fa4_sm80` and the device-specific A100 tests for changes to these
routes; [benchmarking](../benchmarking.md) describes complete-call measurement.
