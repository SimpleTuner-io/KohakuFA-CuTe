# GB10

Standard APIs support SM121 on [Linux ARM64](../installation.md#gb10-on-linux-arm64).
Additional shared schedules are opt-in on the pinned runtime:

```python
from kohakufa_cute.fa4_sm80.gb10 import scaled_dot_product_attention
out = scaled_dot_product_attention(q, k, v, is_causal=True)
```

## Shared selection

The device is a full 48-SM NVIDIA GB10 with 101376-byte opt-in shared-memory
capacity. Inputs are B1, contiguous aligned equal-shape FP16/BF16 MHA, without
mask/dropout/GQA, compilation, deterministic mode, or unsupported scales.
Tuned scales are positive normal FP32 through `2e38`.

| Workload | Tuned family |
| --- | --- |
| Training D128 | H4/H16; dense S512/S1024/S4096; causal S512/S4096 |
| Forward-only D128 | H16; S128/S512/S1024/S4096, except BF16 dense S512 |
| Forward-only D16/D64/D256 | H16/S128, both visibility modes |
| Forward-only D256 | H16/S512/S1024/S4096, both visibility modes |
| Forward-only D64 | H16/S4096, both visibility modes |

Other calls retain ordinary strict CuTe. Forward-only selection checks the live
gradient state and uses a separately qualified native inference runner.
The standard SM121 D256 query-gradient owner shares QK/dP across its full output
width; it is separate from the opt-in shared entry. All use
[the same arithmetic](../precision.md).
