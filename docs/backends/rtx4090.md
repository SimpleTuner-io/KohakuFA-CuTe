# RTX 4090

The standard APIs automatically select bounded tuned training schedules on the
[pinned runtime](../installation.md#qualified-tuned-runtime). The target is a
full 128-SM RTX 4090 with 101376-byte opt-in shared-memory capacity.

## Selection

Inputs are B1/H16, contiguous, 16-byte-aligned, equal-shape FP16/BF16 MHA.
Gradients must be enabled and at least one input must request a gradient.
Dense and causal families are:

| Square length | Head dimension |
| --- | --- |
| 128 | 16 |
| 1024 | 64, 128 |
| 4096 | 64, 128 |

Equal-head MHA accepts either `enable_gqa` value. Masks, dropout, genuine GQA,
other layouts/sizes, inference, compilation, deterministic mode, and unsupported
scales retain ordinary CuTe dispatch. Tuned scales must be positive normal FP32
values through `2e38`.

Short calls use exclusive gradient ownership and measured product/statistics
layouts. Long calls use shared joint backward and causal head grouping; the
S1024 route combines live metadata checks and the cached native runner behind
one host boundary. Only immutable configuration is cached, never input pointers.
All routes retain [the same arithmetic](../precision.md).

## Evidence

[The RTX 4090 report](../../results/rtx4090.json) combines the refreshed default
60-case grid with the latest short and S1024 public-call studies. Each retained
cell identifies its source cohort and timing boundary. Measurements use a full
device at 400 W; older 450 W tuning results are superseded.

Graph and eager improvements are distinct. The original S1024 candidate's eager
regression is retained as experiment evidence; the current host route has its
own qualification. Atomic dQ can vary between runs while remaining within the
per-component norm contract. See [determinism](../determinism.md).
